# Contributing to FlowPayroll Freelancer Payment Resources

Thanks for helping keep this collection relevant and reliable for independent professionals receiving payments internationally.

## Proposing a new resource

1. Fork the repository and work in a separate branch.
2. Place your suggestion in the best-matching section, using the existing entry style: `- **[Resource](https://example.com)** — A short, neutral explanation of its purpose.`
3. Check the provider's published information before describing supported countries, fees, payment methods, or restrictions.
4. Submit a pull request that explains what you changed and how it helps freelancers or contractors.

## Editorial standards

- **Be precise:** avoid claims about processing speeds, pricing, partnerships, or support that cannot be verified.
- **Stay relevant:** include tools or information directly useful for collecting, transferring, or managing contractor payments.
- **Prevent repetition:** search the existing sections before suggesting an item.
- **Keep entries readable:** generally use one entry per line and alphabetical order when practical.
- **Protect users:** call attention to network compatibility, irreversible transfers, and regional restrictions where relevant.

## Corrections and broken links

If a description is outdated or a link no longer works, open an issue or submit a correction pull request. Include a source when possible.
